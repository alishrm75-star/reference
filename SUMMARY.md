## 💡 Примеры использования

### Поиск страницы
```
1. Открыть http://localhost:3000/ref
2. Ввести в поиск "master"
3. Найдено 10 страниц с "master" в названии
4. Клик на карточку → просмотр
```

### Навигация между страницами
```
1. Открыть /ref/auth
2. Кнопка "Next" → переход на следующую страницу
3. Кнопка "Prev" → возврат назад
4. Кнопка "Назад к каталогу" → /ref
```

### Копирование ссылки
```
1. Открыть любую страницу, например /ref/select_services_default
2. Кнопка "Копировать ссылку"
3. В буфере: http://localhost:3000/ref/select_services_default
4. Можно поделиться deep-link
```

## 🔧 Техническая реализация

### Переписывание путей

**До** (исходный HTML):
```html
<style>
@font-face {
  src: url("./media/inter-regular.woff2");
}
</style>
```

**После** (переписанный HTML):
```html
<style>
@font-face {
  src: url("/ref-assets/fonts/inter-regular-GS5EHSMB.woff2");
}
</style>
```

### TypeScript типы

```typescript
interface RefMapItem {
  slug: string;           // "select_master_default"
  title: string;          // "Select Master Default"
  srcHtmlPath: string;    // "html/select_master_default.html"
  file: string;           // "select_master_default.html"
}

type RefMap = RefMapItem[];
```

### Утилиты

```typescript
// Получить всю карту
const refMap = getRefMap();

// Найти страницу
const page = getRefPageBySlug("auth");

// Навигация
const { prev, next } = getAdjacentPages("auth");

// URL-генерация
const url = getRefPageUrl("auth");        // "/ref/auth"
const htmlUrl = getRefHtmlUrl("auth");    // "/ref-html/auth.html"
```
